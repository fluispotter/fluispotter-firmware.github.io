Fluispotter

Fluispotter firmware & software documentation

A single, offline-capable home for the Fluispotter instrument's specifications, testable requirements, architecture notes, component datasheets, and full development history.

The device

Fluispotter is a battery-powered medical fluid-sampling instrument built on an ESP32-S3-WROOM-1 module running MicroPython. Two Faulhaber 1512U gearmotors (324:1, integrated IE2-8 encoders) drive the AC and blood peristaltic pumps. Real-time, safety-relevant pump regulation is offloaded to a ULP RISC-V coprocessor that runs an independent control loop (the bench-validated Simple-P 16-tick regulator), keeping the main asyncio state machine free for the session sequence, sensors, and hub synchronization. Pump power is driven through a TI DAC7574 quad DAC; fluid state is read from VEML6035 spot/line light sensors and analog air/blood sensors.

The software stack

Five shippable components: the ESP32-S3 firmware image, the three ULP binaries (operational / test / test2), the PyQt6 Monitor (passive telemetry) and Control (raw-REPL injection & tuning) desktop apps, and the RPi synchronize-service. A machine-readable requirements registry generates the requirements document and drives the automated verification framework, gated in CI.
