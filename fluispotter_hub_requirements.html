1. Document Overview

This document collects all verifiable requirements for the Fluispotter Hub — the Raspberry Pi Buildroot appliance and the synchronize-service platform it runs: the appliance image and its A/B update mechanism, the network identity and access control, the service runtime, and the operational procedures (deploy, image-pin integrity, backup). Each requirement carries a stable ID, a class (PLAT platform / NET network / SVC service / OPS operations), a sub-system, a concrete verification method (SSH command, HTTP probe or inspection) and machine-readable limits, so hub health can be checked mechanically. automated QC. This document is generated from the machine-readable registry verification/hub_requirements.py; the document and the registry cannot drift apart.

Each requirement also carries a lock status: a Locked requirement is frozen — its text changes only on the owner's explicit instruction, enforced by a content-hash baseline that fails the build on any unsanctioned edit or removal — whereas an Open requirement may still be revised. New requirements default to Open.
