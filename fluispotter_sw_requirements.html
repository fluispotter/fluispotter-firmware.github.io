1. Document Overview

This document is the testable software-requirements specification for the Fluispotter device software: the ULP pump regulator, the main-CPU MicroPython firmware, the Monitor and Control desktop applications, the RPi synchronize service, and the build/deploy process gates. Requirements are derived from the Device Specification Repository (v2.11), the project rule notes/checklists, and the implemented code.

Each requirement is a single testable shall-statement with a stable ID and a verification class: SW (verifiable headless — unit test, static/source analysis, parsing) or MECH (requires the physical board / pump mechanics — bench/HIL stage). This document is generated from the machine-readable registry verification/requirements.py, which the automated verification framework also uses for test tagging and coverage reporting — the document, the tests, and the report cannot drift apart.

Each requirement also carries a lock status: a Locked requirement is frozen — its text changes only on the owner's explicit instruction, enforced by a content-hash baseline (SWR-511) that fails the build on any unsanctioned edit or removal — whereas an Open requirement may still be revised. New requirements default to Open.
